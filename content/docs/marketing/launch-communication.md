Northstar introduces offline checklists for scheduled maintenance visits. The release message is about technicians recording work in areas with weak connectivity.

## A release is ready to announce when

Engineering confirms that the feature is enabled for the named audience. Support has a troubleshooting note. Sales knows which plans include it. Marketing has tested every screenshot against the release candidate.

## What we can say

Say “complete an assigned checklist without a connection, then sync when you are back online.” Do not say “Fieldbook works entirely offline.” Scheduling new visits and downloading attachments still require a connection.

## Timing

Publish the announcement after Engineering confirms the rollout. If a release slips, move the announcement with it. Update the website, customer email, and sales note from the same approved description.

For promised release dates, use the [roadmap commitments](/docs/sales/roadmap-commitments) policy.
